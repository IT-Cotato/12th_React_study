여기 간단한 Count 앱이 하나 있다. 해당 앱은 증가, 감소, 리셋을 이용해 CountDisPlay, CountOutside 컴포넌트에서 값을 보여 주기 위해선 상태를 정의 해야한다. 하지만 두 곳에서 보여주기 위해선 강제로 App 컴포넌트에서 상태와 함수를 정의 하고 하위 컴포넌트에 Props를 계속 넘겨주는 Props drilling 방식을 사용해야한다.

우리는 이와 같은 상황을 방지하기 위해서 전역 상태 관리를 사용한다.

### Context API

```tsx
const CounterContext = createContext(null);
```

⇒ context 객체는 대문자로 생성.

```tsx
<CounterContext value={{ count, increment, decremnet, reset }}>
  <Count />
  <CountOutside />
</CounterContext>
```

⇒ 태그로 묶어서 사용하는 방식 value값 사용 가능

하지만 타입을 아래와 같이 지정해줘야한다.

```tsx
type CounterContextType = {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
};
```

CreateContext도 타입 제네릭 정의 해주기

```tsx
export const CounterContext = createContext<CounterContextType | null>(null);
```

하위 컴포넌트에서 받아서 사용하려면 useContext hook을 사용하면 된다.

```tsx
const { count } = useContext(CounterContext)!;
```

⇒ !는 보정 연산자

### Context API 개선

컨텍스트의 경우에는 별도의 파일로 분리해서 작성하는게 코드의 유지보수기나 가독성을 더 좋게 만든다.

src ⇒ context ⇒ string 형식으로 만들기

CounterContext.ts

```tsx
import { createContext } from "react";

type CounterContextType = {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
};
export const CounterContext = createContext<CounterContextType | null>(null);
```

CounterProvider.tsx

```tsx
import { useState } from "react";
import { CounterContext } from "./CounterContext";

export default function CounterProvider({
  children,
}: {
  children: React.ReactNode;
}) {
  const [count, setCount] = useState(0);
  const increment = () => {
    setCount((count) => count + 1);
  };
  const decrement = () => {
    setCount((count) => count - 1);
  };
  const reset = () => {
    setCount(0);
  };
  return (
    <>
      <CounterContext value={{ count, increment, decrement, reset }}>
        {children}
      </CounterContext>
    </>
  );
}
```

컨텍스트 객체로 공급하고 있는 데이터를 간편하게 활용하는법

useCounter.ts

```tsx
import { useContext } from "react";
import { CounterContext } from "./CounterContext";

export default function useCounter() {
  const context = useContext(CounterContext);
  if (!context) {
    throw new Error("useCounter는 CounterProvider 안에서만 사용가능합니다.");
  }
  return context;
}
```

### Context API 개선 리렌더링

버튼을 누를때마다 리렌더링이 발생하는데 이는 React.memo로 메모이제이션해도 해결되지 않는다.

CounterProvider에서 제공하는 count 상태의 객체 값이 변하면서 다시 리렌더링 되기 떄문이다.

이를 해결하기 위해서는 해당 객체값 자체를 메모이제이션 하면 된다.

```tsx
type CounterContextType = {
  count: number;
};
type CounterContextActionType = {
  increment: () => void;
  decrement: () => void;
  reset: () => void;
};

export const CounterContextAction =
  createContext<CounterContextActionType | null>(null);
```

useCounter에 추가

```tsx
export function useCounterAction() {
  const context = useContext(CounterContextAction);
}
```

```tsx
const memoization = useMemo(() => ({ count, incerement, decrement, reset }), []);

return (
	<>
	<CounterContextAction value={memoization}>
		<CounterContext value={{ count }}>{children}</CounterContext>
		</CounterContext>
)
```

### reducer

src ⇒ reducer ⇒ counterReducer.ts 생성

```tsx
export default function counterReducer(count, action) {
	switch(action.type) {
		case "INCREMENT"
			return count + 1;
		case "DECREMENT"
			return count - 1;
		case "RESET"
			return 0;
		default:
			return count;
	}
}
```

CounterProvider 상태 변경

```tsx
const [count, countDispatch] = useRedeucer(counterReducer, 0);

<>
	<CounterContextAction value={{ countDispatch }}
</>
```

⇒ 캡슐화 필요 없음

하지만 이렇게 해도 dispatch의 상태가 변경되어 해당문까지 객체로 만들어야 리렌더링이 발생하지 않는다.

CounterContext.ts

```tsx
type CounterContextActionType = React.ActionDispatch<
  [action: { type: string }]
>;
```
