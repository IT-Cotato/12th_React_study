### 컴포넌트 분리하기

```tsx
type ButtonProps = React.ComponentPropsWithoutRef<"button">;
```

⇒ without-ref는 ref 속성을 사용하지 않는 조건에서의 버튼 태그에서 사용할 수 있다. (범용성)

범용적인 Input 태그 만들기

```tsx
type ReactInputType = React.InputHTMLAttributes<HTMLInputElement>["type"];
type InputProps = Omit<React.ComponentPropsWithoutRef<"input">, "type"> & {
  type?: Exclude<ReactInputType, "radio" | "checkbox">;
};
```

⇒ Omit을 이용해서 Type을 Optional로 지정해 범용적인 태그에서 Radio와 Check 박스만 제거한 상태로 만들 수 있다.

Check 박스도 같은 방식으로 해줄 수 있다.

```tsx
type CheckboxProps = Omit<React.ComponentPropsWithoutRef<"input">, "type"> & {
  type?: "checkbox";
  parentClassName: string;
};
```

### 불필요한 리렌더링을 관리하기

onSubmit 이벤트를 활용하면 엔터와 버튼 태그의 처리를 동시에 할 수 있다.

```tsx
const addTodo = (text: string) => {
  setTodos((todos) => [
    ...todos,
    {
      id: Date.now(),
      text,
      completed: false,
    },
  ]);
};
```

⇒ 할 일을 추가할 때 상태 관리를 하기 위해서는 SetTodos를 콜백함수의 형태로 정의 해야한다.

id 값은 중복되지 않기 위해서 Date.now()로 현재 시간으로 했으나 연속적인 클릭을 할 경우에는 중복 될 수 있음으로 실제 프로젝트에서는 비권장한다.

```tsx
if (text.trim() === "") return;
```

⇒ 인풋이 비었을때 Add 버튼을 눌러도 리렌더링이 발생하지 않게 만드는 코드

### 구조분해 할당 예시

| **대상**                  | **예시**                    | **의미**                            |
| ------------------------- | --------------------------- | ----------------------------------- |
| **배열 구조분해**         | const [a, b] = arr;         | 순서대로 변수에 바인딩              |
| **객체 구조분해**         | const { x, y } = obj;       | key 이름으로 매칭되어 변수로 바인딩 |
| **React에서 핵심 사용처** | useState, props, useReducer | 필요한 값만 간단하게 꺼내기         |

---

❌ 구조분해 안 쓰면

```tsx
function Profile(props: Props) {
  return (
    <div>
      {props.name}
      {props.email}
      {props.age}
    </div>
  );
}
```

✅ 구조분해 쓰면

```tsx
function Profile({ name, email, age }: Props) {
  return (
    <div>
      {name}
      {email}
      {age}
    </div>
  );
}
```
