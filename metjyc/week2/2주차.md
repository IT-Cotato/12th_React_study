## React 자료형의 출력

1. 기본 자료형

   - 기본 자료형의 출력은 중괄호를 통해서 {} 모두 가능하다.
   - null, undefined, boolean 값은 String() 메소드를 통해서 변환 시켜줘야 출력이 가능하다.

1. 참조 자료형
   - 참조 자료형에서 배열은 중괄호 {} 출력 가능.
   - 객체는 JSON.stringify를 통해서 해야한다. ⇒ JSON 문자열 형태
   - 함수, Date 객체, 정규식은 래퍼 객체가 존재하기 때문에 .toString() 메소드를 사용해주면 출력 가능
   - new Set, Map 데이터는 Json.stringify(Array.from())을 통해서 변환한다.

## TS React

타입스크립트 리액트는 컴포넌트로 정보를 넘겨줄 때 통상적으로 Props라고 적는다.

그리고 해당 속성에 대한 타입을 지정해줘야한다. ex) props({name: string, age: number})

## 비구조화 할당

```jsx
const {
  numberValue,
  stringValue,
  booleanValue,
  arrayValue,
  objectValue,
  handleClickValue,
} = props;
```

## 타입 쉽게 알아내기

- 정보를 받는 Props의 타입을 지정하기 어렵다면 해당 앱 컴포넌트로 이동해서 컴포넌트로 넘겨주는 정보의 빨간줄에 커서를 갖다대면 정보의 타입이 나와 쉽게 Props 타입 지정이 가능하다.
  ⇒ 다만 권장하지 않음

## React에서 children으로 props 전달하는법

닫힌 태그 vs 열린 태그

- 내용이 없는 경우 닫힌 태그 있는 경우 열린 태그를 사용한다

```jsx
<button>login<button/>  // 내용이 있는 경우
```

```jsx
<br /> // 내용이 없는 경우
```

이 경우에 열린 태그로 전환하여 children을 전달하여 React.Element 옵션을 적용하여 React 전용타입 Children으로 props를 전달할 수 있게 된다

그렇다면 React.ReactElement vs React.ReactNode

- React.ReactNode 타입이 훨씬 더 범용적인 타입이다.

## Props로 전달하는가? Children으로 전달하는가?

**✅ JSX 요소의 속성에 사용되는 경우**

JSX 요소의 속성에 사용되는 값은 props로 전달합니다.

예를 들면 id, className와 같은 속성이 있습니다.

```jsx
function Button({ id, className }: { id: string, className: string }) {
  return (
    <button id={id} className={className}>
      버튼
    </button>
  );
}

export default function App() {
  return (
    <>
      <Button id="btn" className="btn btn-primary" />
    </>
  );
}
```

**✅ JSX 요소의 콘텐츠에 사용되는 경우**

JSX 요소에서 콘텐츠에 사용되는 경우는 children으로 전달합니다.

```jsx
function Button({ children }: { children: React.ReactNode }) {
  return <button>{children}</button>;
}

export default function App() {
  return (
    <>
      <Button>
        <span>✅</span> 성공
      </Button>
    </>
  );
}
```
