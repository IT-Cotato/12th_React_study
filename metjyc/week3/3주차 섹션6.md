### Hook이란?

함수형 컴포넌트에서 상태 관리와 생명 주기 기능 및 부가적인 기능을 활용할 수 있게 도와주는 새로운 기능

### UseState에 대하여

```jsx
const [state, setState] = useState < Type > initialState;
```

state ⇒ 실제 상태 값이 할당될 변수

setState ⇒ 상태값을 업데이트 하는 함수

상태의 초기 값은 미 설정시 undefined

<Type> ⇒ 타입 지정 부분은 변환하는 타입이 전, 후가 같으면 생략 가능.

하지만 타입이 전, 후가 다르다면 Union 타입을 이용해

```jsx
const [state, setState] = (useState < number) | (string > 0);
```

⇒ 이와 같이 추후 다른 값이 될 수 있음을 선언 해줘야함.

### 객체 상태 업데이트

```jsx
const [userInfo, setUserInfo] = useState({
	name: "Jack",
	age: 20,
	gender: "male",
});

const handleUpdateUserInfo = () => {
	setUserInfo((userInfo) => ({
		...userInfo,
		name: "mike",
	});
};
```

이름, 나이, 성별과 같이 정의할 값이 많아진다면 객체 상태를 선언하는 것이 효율적이다. 다만 이러한 객체 상태를 업데이트 할 경우, 일부분 값만 변경하고 싶다면 spread 연산자를 이용해서 바꿔줘야 다른 상태가 사라지지 않는다.

### 활용 예시

![image.png](./asset/3주차%20섹션6%2012.png)

먼저 useState 사용할 때와 같이 useReducer로 선언을 해준다.

```jsx
const [count, countDispatch] = useReducer(reducer, 0);
```

⇒ useReducer의 첫번째 인자값은 Action 값이고 두번째 인자는 초기 상태 값이다. 이때 첫번째 인자값은 제네릭값의 지정이 어려워 유추 기능을 이용하도록 한다.

그 후 따로 Action 함수를 선언을 해준다.

```jsx
function reducer(count: number, action: { type: string }) {
  switch (action.type) {
    case "INCREMENT":
      return count + 1;
    case "DECREMENT":
      return count - 1;
    case "RESET":
      return 0;
    default:
      return count;
  }
}
```

⇒ 이때 함수 내에서 인자로 받는 첫번째 값은 상태값이고 두번째는 액션값이다.

그후 버튼에 함수 형태로 전달하여 마무리 하면 된다.

```jsx
<button onClick={() => countDispatch({ type: "DECREMENT" })}>감소</button>
<button onClick={() => countDispatch({ type: "RESET" })}>초기화</button>
<button onClick={() => countDispatch({ type: "INCREMENT" })}>증가</button>
```
