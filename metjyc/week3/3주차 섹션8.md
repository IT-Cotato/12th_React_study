### Classnames를 이용해서 두개 이상의 스타일 선언을 적용시키는 법

![image.png](./asset/3주차%20섹션8%205.png)

⇒ 두개 이상의 스타일을 적용 시키는 경우 백틱을 이용해서 템플릿 리터럴로 정의 해줘야한다.

위 방식보다 간단하게 하려면

```jsx
const cx = classNames.bind(styles);

<button className={cx("btn", "is-active")}>버튼</button>;
```

이와 같이 클래스 결합을 통해서 정의해주면 편하게 적용이 가능하다.

삼항 연산자 boolean 값을 이용한 스타일 적용법

![image.png](./asset/3주차%20섹션8%206.png)

⇒ 삼항 연산자를 통한 적용법은 위와 같다.

1. 템플릿 리터럴 방식

   삼항 연산자를 이용해서 로그인 상태일 경우 스타일을 바꾸고 싶다면 isLoggedIn을 템플릿 리터럴 안에 넣고 값이 true인 경우 style[”is-active”]과 같이 스타일 내부에 클래스 형태로 정의된 스타일을 대괄호로 감싸준다.

2. 클래스 결합 방식

   클래스 결합 방식의 경우 중괄호로 내부에서 삼항연산자를 사용해주면 된다.

### Styled-component에 대하여

styled-component의 기본 사용

```jsx
CONST 컴포넌트이름 = styled.[태그명]`
	스타일 속성;
`;
```

태그 적용법은

```jsx
<Title>Hello, ReactJS!</Title>
```

⇒ 과 같이 태그로 감싸주면 된다.

타입을 지정해주고 컴포넌트 태그에서 적용시키는 방법이 있는데

```jsx
const Title = styled.h1<{ $color: string; }>`
	color: ${(props => props.$color};
`;

<Title $color="red">Hello, ReactJS!</Title>
```

이렇게 컴포넌트 내부에서 타입을 지정해주면 컴포넌트 내부에서 스타일 변경이 가능하다.

확장하는 방식

```jsx
CONST BigTitle = styled(Title)`
	font-size: 50px;
`;

<BigTitle>Hello, Big Title!<BigTitle>
```

⇒ 위 타이틀 태그를 기반으로 더 확장하고 싶은 스타일이 있다면 styled() 괄호 내부에 기존 스타일 선언문을 포함해주면 된다. 이미 타입이 정의된 선언문을 참조하므로 따로 타입을 표기해줄 필요가 없다.

### 속성 as와 keyframes에 대하여

또한 as 라는 속성을 이용해서 기존 스타일 선언문에 영향을 주지 않으면서 태그를 바꿀 수 있다.

```jsx
<Title as="p">Hello, ReactJS!</Title>
```

keyframe은

```jsx
const fadeIn = keyframes`
	from{
		opacity: 0;
	to{
		opacity: 1;
	}
`;
```

이러한 예시를 통해 애니메이션 작업을 진행할 수 있다.

### MixIN 추가 방식

```jsx
const boxShadowMixin = css`
	box-shadow: 0px 10px 10px rgba(0, 0, 0, 0.5);
`;

const BlueBoarderWrapper = styled(wrapper)<{ $shadow: boolean {>`
	border-color: blue;
	${(props) => props.$shadow && boxShadowMixin} // shadow를 참조했는데 true 라면 boxshadowMixIn을 적용하겠다.
`;

<BLueBorderWrapper $shadow> // true 값으로 전달 가능

```

### Tailwind css

스타일을 미리 정의된 클래스 대신, 작은 스타일 속성을 유틸리티 클래스로 제공해 개발자가 각 요소에 필요한 스타일을 조합해 나가는 방식

TailWind-Merge 패키지를 사용하면 중복되는 속성을 제거하고 가독성을 높일 수 있다.

```jsx
<button className={twMerge(`~~~))}>Click Me </button>
```

TailWind를 잘 사용하기 위해선 공식문서를 참고해서 접두사를 학습할 것

개인적으로는 Styled-component가 더 사용하기 편리한 것 같다.
