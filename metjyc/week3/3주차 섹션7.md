### 조건부 렌더링

조건에 따라 적절한 UI를 렌더링 하는 것

두개 이상의 컴포넌트를 렌더링 하고싶다면

```jsx
return (
  <>
    <UserView />
    <UserInfoView />
  </>
);
```

⇒ 위 예시와 같이 Fragment 태그를 이용해서 감싸줄 것.

조건부 렌더링은 if와 switch 문을 이용하여 설정 가능하다.

### 반복문을 이용한 렌더링

for문을 이용한 예시

![image.png](./asset/3주차%20섹션7%203.png)

⇒ 사진에서는 없지만 리액트에서 반복문 렌더링을 진행할 때, 고유 key값을 속성 값으로 반드시 추가해줘야 한다.

```jsx
items.push(<li key={i}>{fruit[i]}<li/>);
```

그리고 for문 보다는 map 메소드를 이용해서 새 배열을 만들어 반복 렌더링을 구현하는 것을 추천한다.

### map 메소드를 이용한 반복 렌더링

![image.png](./asset/3주차%20섹션7%205.png)

⇒ map 메소드 안에 있는 인자는 첫번째는 배열 내에 밸류값을 뜻하고 두번째는 순서 인덱스를 뜻한다.

### key 속성 고유값에 대하여

![image.png](./asset/3주차%20섹션7%206.png)

⇒ index 값을 키값으로 쓰는건 배열에 순서 변화가 일어났을때 충돌이 발생하므로 바람직하지 않다.

UUID 값을 지정해주는 라이브러리를 사용하여 고유한 id값을 지정하는 방식을 권장.

### Filter 메소드

```jsx
const filterItems = items.filter((element) => element.name === "Apple");
```

⇒ 원하는 값만 도출 가능
