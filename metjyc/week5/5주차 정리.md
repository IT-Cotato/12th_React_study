## 제어 컴포넌트

### 한 줄 입력 요소

한줄로 여러개의 입력 요소를 받는법

```tsx
export default function Input() {
  const [formState, setFormState] = useState({
    email: "",
    password: "",
  });
```

⇒ 이렇게 할 경우 이메일과 패스워드의 인풋 값을 하나의 상태로 처리 할 수 있다.

### 체크박스 한줄 입력 요소

체크 박스 또한 위와 같은 방법으로 정의가 가능하다.

```tsx
export default function Checkbox() {
  const [formState, setFormState] = useState({
    chk1: false,
    chk2: false,
  });
```

이벤트 핸들러의 경우 함수 참조형태로 변경해주면 된다.

```tsx
const handleFormStateChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  setFormState((formState) => ({
    ...formState,
    [e.target.name]: e.target.checked,
  }));
};
```

## 비제어 컴포넌트

비제어 컴포넌트는 제어 컴포넌트와 다르게 상태를 사용하지 않는다.

```tsx
export default function Input() {
  const inputRef = useRef<HTMLInputElement>(null);
  const pwRef = useRef<HTMLInputElement>(null);

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    console.log(inputRef.current?.value);
    console.log(pwRef.current?.value);
  };
```

⇒ 또한 useRef를 사용할 경우 상태와 다르게 여러개의 입력 값을 한번에 처리하는 방식을 권장하지 않으므로 한줄 한줄 선언 해주는 것이 옳다.

또한 인풋의 입력값을 바로 다 알 수는 없고 이벤트 핸들러에 콘솔로그를 이용해서 밸류값을 보는 것이 일반적이다.

### 비제어 컴포넌트 체크박스

개인정보 동의 체크 박스에 체크 하지 않았을 경우 아래와 같은 코드로 필수 값임을 강조할 수 있다.

```tsx
const privacy = privacyRef.current?.checked;
if (!privacy) {
  alert("개인정보에 동의해주세요");
  return;
}
```

### 라디오

defaultchecked 요소를 사용하면 기본 체크 값을 설정할 수 있다.

라디오는 폼 데이터 객체를 생성해서 get 메소드를 사용해서 값을 가져오는 방식으로 사용해야한다.

```tsx
const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
  e.preventDefault();
  const formData = new FormData(formElRef.current!);
  console.log(formData.get("option"));
};
```
