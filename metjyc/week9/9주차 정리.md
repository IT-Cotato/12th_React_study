### zustand

독일어로 상태라는 뜻을 의미한다.

설치 명령어

```tsx
npm install zustand
```

zustand는 store 파일을 통해 관리할 수 있다. ex) countStore.ts

```tsx
import { create } from "zustand";

type CountStore = {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
};

export const useCountStore = create((set, get) => ({
  count: 0,
  decrement: () => set((state) => ({ count: state.count - 1 })),
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));
```

zustand는 함수 정의할 때 항상 콜백함수 값을 가진다.

set은 자신의 스토어 파일의 데이터를 변경할 때 사용하는 상태변경함수 역할을 한다.

get은 자신의 상태값을 가져오는 역할을 하는 함수가 온다.

사용예시

```tsx
import { useCountStore } from "../store/countStore";

const increment = useCountStore((store) => state.increment);

<button onClick={increment}>
```

### zustand 매개 변수

```tsx
import { create } from "zustand";
type CountStore = {
  count: number;
  increment: (amount: number) => void;
  decrement: () => void;
  reset: () => void;
};
export const useCountStore = create<CountStore>((set) => ({
  count: 0,
  increment: (amount: number) => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 }),
}));
```

```tsx
import { useCountStore } from "../store/countStore";

export default function CountButton() {
  console.log("CountButton");
  const increment = useCountStore((state) => state.increment);
  const decrement = useCountStore((state) => state.decrement);
  const reset = useCountStore((state) => state.reset);
  return (
    <>
      <button onClick={decrement}>감소</button>
      <button onClick={reset}>리셋</button>
      <button onClick={() => increment(5)}>증가</button>
    </>
  );
}
```

⇒ 값의 증가를 5씩 하고싶다면 메서드를 다시 재정의 하면 된다.

async await 비동기 활용 방법

```tsx
import { create } from "zustand";
type CountStore = {
  count: number;
  increment: (amount: number) => void;
  decrement: () => void;
  reset: () => void;
};
export const useCountStore = create<CountStore>((set) => ({
  count: 0,
  increment: async (amount: number) => {
    await new Promise((resolve) => setTimeout(resolve, 1000));
    set((state) => ({ count: state.count + 1 }));
  },
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 }),
}));
```

### zustand / persist 미들웨어(middleware)

스토어의 동작을 확장하거나 가로채서 제어할 수 있도록 도와주는 기능

```tsx
import { create } from "zustand";
type CountStore = {
  count: number;
  increment: (amount: number) => void;
  decrement: () => void;
  reset: () => void;
};
export const useCountStore = create<CountStore>()(
  persist(
    (set) => ({
      count: 0,
      increment: (amount: number) => {
        set((state) => ({ count: state.count + 1 }));
      },
      decrement: () => set((state) => ({ count: state.count - 1 })),
      reset: () => set({ count: 0 }),
    }),
    {
      name: "count-storage",
      storage: createJSONStorage(() => sessionStorage), // 세션 스토리지
    }
  )
);
```

zustand의 미들웨어 기능을 활용해서 persist를 사용해 로컬 스토리지를 따로 작성하지 않아도 저장할 수 있는 기능이 있다. 세션 스토리지 사용을 원할 경우 객체 값 내부에 선언해주면 된다.

subscribeWithSelector

특정 상태가 변경될 때를 감지해서 특정 로직을 수행할 수 있는 구독 기능을 사용할 수 있게 해주는 미들웨어.

```tsx
import { create } from "zustand";
type CountStore = {
  count: number;
  increment: (amount: number) => void;
  decrement: () => void;
  reset: () => void;
};
export const useCountStore = create<CountStore>()(
  subscribeWithSelector(
    persist(
      (set) => ({
        count: 0,
        increment: (amount: number) => {
          set((state) => ({ count: state.count + 1 }));
        },
        decrement: () => set((state) => ({ count: state.count - 1 })),
        reset: () => set({ count: 0 }),
      }),
      {
        name: "count-storage",
        storage: createJSONStorage(() => sessionStorage), // 세션 스토리지
      }
    )
  )
);
```

```tsx
import { useEffect } from "react";
import CountGroup from "./CountGroup";
import { useCountStore } from "../store/countStore";

export default function Count() {
  useEffect(() => {
    const unsubscribe = useCountStore.subscribe(
      (state) => state.count,
      (newCount) => {
        console.log("newCount: " + newCount);
      }
    );
    return () => {
      unsubscribe();
    };
  }, []);
  return (
    <>
      <CountGroup />
    </>
  );
}
```

⇒ 첫번째 매개변수는 내가 감시할 state를 적어준다. 두번째는 상태가 변경되었을때 실행할 콜백 함수를 넣어준다.

zustand immer

자동으로 불변성을 처리해주는 미들웨어 ⇒ redux는 자동으로 적용되어 있음.

설치 코드

```tsx
npm install immer
```

```tsx
import { create } from "zustand";
import { immer } from "zustand/middleware/immer";

type CountStore = {
  count: number;
  increment: (amount: number) => void;
  decrement: () => void;
  reset: () => void;
};
export const useCountStore = create<CountStore>()(
subscribeWithSelector(
	persist(
	immer((set) => ({
	  count: 0,
	  increment: (amount: number) => {
		  set((state) => ({ count: state.count + 1 });
	  },
	  decrement: () => set((state) => { count: state.count - 1 }),
	  reset: () => set({ count: 0 }),
		})),
			{
				name: "count-storage",
				storage: createJSONStorage(() => sessionStorage), // 세션 스토리지
			}
		)
	)
);

```

⇒ immer는 콜백함수 매개변수 부분만 감싸준다. 이렇게 진행하면 불변성 관리를 해줄 수 있다.

### zustand Devtool

Redux Toolkit 과 연동해서 사용 가능

```tsx
import { create } from "zustand";
import { immer, devtools } from "zustand/middleware/immer";

type CountStore = {
  count: number;
  increment: (amount: number) => void;
  decrement: () => void;
  reset: () => void;
};
export const useCountStore = create<CountStore>()(
devtools(
	subscribeWithSelector(
		persist(
		immer((set) => ({
		  count: 0,
		  increment: (amount: number) => {
			  set((state) => ({ count: state.count + 1 });
		  },
		  decrement: () => set((state) => { count: state.count - 1 }),
		  reset: () => set({ count: 0 }),
			})),
				{
					name: "count-storage",
					storage: createJSONStorage(() => sessionStorage), // 세션 스토리지
				}
			)
		)
	)
);

```

프로덕션 모드에서 사용을 원치 않는다면

감싸준 내부에서 enabled: 속성값을 변경 해준다.

그러면 개발 모드에서만 연동된다.

```tsx
{
	enabled: false,
}

{
	enable: import.meta.env.MODE === "development",

}
```
