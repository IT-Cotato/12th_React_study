## 더이상 CRA(npx create-react-app)을 사용하지 않는 이유

- 더이상 업데이트 되지 않는 CRA 모듈
- Vite의 출현으로 필요한 모듈만 사용해서 패키지 설치 및 활발한 유지보수와 빠른 개발 환경 제공
- WebPack 기반 서버보다 Vite 개발 서버가 네이티브 ES모듈 활용 및 온디맨드 컴파일로 속도가 더 빠르다.

## Vite란

- index.html을 초기 진입점으로 업로드하여 애플리케이션을 시작한다.
- npm run dev로 개발 서버를 시작한다.
- 기존 CRA 방식과 다르게 프로젝트 생성에 필요한 모듈만을 사용하여 애플리케이션을 구축한다.

## JSX란?

- Javascript + XML을 결합한 것. 메타(구 페이스북) 팀이 편의성을 위해서 제작한 것
- 그러나 브라우저는 이를 인식할 수 없기 때문에 중간 트랜스폼을 거쳐야한다.

## 컴포넌트

### 개념

- UI를 구성하는 독립적이고 재사용 가능한 작은 단위
- ES7 React snippet을 이용해 rfc로 함수형 컴포넌트의 기본구조를 만들 수 있다.
- rcc = 클래스형 컴포넌트
- 클래스형 컴포넌트는 함수형 컴포넌트에 비해 문법이 복잡하고 가독성이 떨어진다.
- Hook이 등장한 이후로는 잘 사용하지 않는다.

### 활용

- 컴포넌트 파일을 따로 생성 후 app.jsx에서 import 라는 개념으로 불러온 후 ex) <Header />식으로 셀프 클로징 해준다.
- 함수 표현식

- export default 라는 뜻은 임포트 할 때 자유롭게 이름을 지정해줄 수 있다는 것을 말한다. (단, 웬만하면 동일한 이름으로 사용하기)

## React

- 불필요한 랜더링을 방지하기 위해서<div> 대신 빈 태그인 <> React.Fragment를 사용한다.
- HTML에서는 태그를 무조건 닫지 않아도 괜찮지만 React는 반드시 닫아줘야한다.
