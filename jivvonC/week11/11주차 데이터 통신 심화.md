### useTransition(fetch) 소개

useTransition

- React18부터 도입
- 상태 업데이트를 낮은 우선순위에 트랜지션(Transition)으로 처리
- React19부터는 비동기 함수도 처리할 수 있도록 기능이 확장

트랜지션(Transition)

React.js에서 코드를 낮은 우선순위(리액트가 더 중요한 작업이 끝나고 여유가 있을때)로 처리한다는 의미

```tsx
const [isPending, startTransition] = useTransition();

//isPending: 현재 실행중인 트랜지션이 있으면 true, 없으면 false
//startTransition: 코드를 트랜지션으로 실행할 수 있게 해주는 함수
// 이걸로 감싼 코드는 비긴급 업데이트로 분류, 그동안 isPending은 T, 작업 완료시 F
```

### useTransition + 데이터 패칭 실전

```tsx
import axios from "axios";
import { useEffect, useState, useTransition } from "react";

interface Post {
  id: number;
  title: string;
  views: number;
}
export default function App() {
  const [posts, setPosts] = useState<Post[]>([]);
  const [isPending, startTransition] = useTransition();

  //사이드 effect를 담당하는 useEffect로 useTransition 사용
  useEffect(() => {
    startTransition(async () => {
      const { data } = await axios.get("http://localhost:3000/posts");
      setPosts(data);
    });
  }, []);

  //useTransition은 isPending이 있어서 따로 isLoading같은 상태가 필요 없음
  if (isPending) return <h3>loading..</h3>;
  return (
    <>
      <h3>useTransition</h3>
      <ul>
        {posts.map((post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </>
  );
}
```

### useActionState

form태그의 action속성을 사용하는 방법

폼의 액션 결과를 기반으로 상태를 업데이트 할 수 있도록 도와주는 훅

```tsx
const [state, formAction, isPending] = useActionState(fn, initialState);

//fn: 액션이 발생했을때 실행할 함수 (비동기 함수도 가능)
//initialState: 상태의 초기값 지정

//이렇게 useStateHook의 매개변수를 설정하면 3가지 요소를 포함한 배열을 반환(<- 느낌)
//state: 현재 상태값
//formAction: 폼 액션 함수(action 속성에 활용)
//isPending: 액션 처리중 여부(t/f)
```

```tsx
import { useActionState } from "react";

export default function App() {
  //count는 현재 상태(초기 0), form action이 발생하면 현재상태+1
  const [count, formAction, isPending] = useActionState((count) => {
    return count + 1;
  }, 0);

  //원래 submit은 제출되면 브라우저가 페이지를 새로고침
  //근데 지금은 react가 폼 제출 이벤트를 가로채고
  //해당 액션 함수로 데이터를 전달함
  //브라우저의 기본 동작이 아닌 formAction 함수로 처리

  return (
    <>
      <form action={formAction}>
        <h1>Count: {count}</h1>
        <button type="submit">증가</button>
      </form>
    </>
  );
}
```

```tsx
import { useActionState } from "react";

export default function App() {
  //count는 현재 상태(초기 0), form action이 발생하면 현재상태+1
  const [count, formAction, isPending] = useActionState(
    async (count: number, formData: FormData) => {
      const amount = Number(formData.get("amount"));
      return count + 1;
    },
    0
  );

  //이렇게 form요소의 객체 데이터 값을 가져올 수 있음

  return (
    <>
      <form action={formAction}>
        <h1>Count: {count}</h1>
        <input type="number" name="amount"></input>
        <button type="submit">증가</button>
      </form>
    </>
  );
}
```

### useOptimistic

`낙관적 업데이트`: 서버의 응답을 기다리지 않고 먼저 사용자 인터페이스(UI)를 업데이트 하는 기법

서버 요청이 성공할 것이라고 낙관적으로 가정하고 UI를 먼저 변경하는 방식

그래서 서버에서 요청 실패 시 UI를 다시 원래대로 되돌리는 롤백 로직이 필요함

React19에서는 이걸 간편하게 할 수 있도록 useOptimistic hook이 새롭게 도입됨

### use + suspense

use: Promise 객체를 동기 함수처럼 사용할 수 있게 해주는 기능

suspense: 컴포넌트에서 비동기 처리가 완료될 때까지 대기하게 하는 동안 fallback 속성에 지정된 UI를 표시하는 역할

![image.png](attachment:8b2ecc0b-7201-4f15-9e81-d06ef21cdc54:image.png)

suspense 컴포넌트로 promise 객체를 전달해주는 컴포넌트를 감싸고 promise 객체를 전달 받은 하위 컴포넌트는 이 promise 객체를 활용해서 use 훅을 사용함.

use 훅은 비동기가 처리가 될 때까지 대기하게 되고, 처리 이후 결과를 변수에 할당할 수 있게 되고 그 할당한 변수를 가지고 컴포넌트에서 데이터를 활용할 수 있게 됨

> async, await 없이도 비동기 함수를 처리해서 컴포넌트에서 사용할 수 있게 됨

```tsx
import { axiosInstance } from "./api/axios";

async function fetchPosts() {
  const { data } = await axiosInstance.get("/posts");
  return data; //promise 객체
}
export default function App() {
  return (
    <>
      //함수의 호출 결과, promise 객체 //비동기 함수 호출 완료될 때까지
      기다려주는 처리가 끝날때까지 보여줄 ui
      <Suspense fallback={<p>Loading...</p>}>
        <Posts promise={fetchPosts()} />
      </Suspense>
    </>
  );
}

//Posts.tsx
export default function Posts({
  promise,
}: {
  promise: Promise<
    {
      id: number;
      title: string;
      views: number;
    }[]
  >;
}) {
  const posts = use(promise);
  return (
    <>
      <pre>{JSON.stringify(posts, null, 2)}</pre>
    </>
  );
}
```

react에서는 아직 async가 붙어있는 컴포넌트를 바로 사용할 수는 없음

그래서 따로 컴포넌트로 분리한다음에 그 컴포넌트에서 use 훅을 사용해서 연동해야함

### error boundary

앱 전체가 종료되어 버리는 crash 현상이 발생했을 때 이러한 문제를 해결하기 위해서 사용되는게

error boundary, 원래는 자바스크립트 오류를 처리하기 위한 특별한 컴포넌트

react-error-boundary 외부 패키지를 이용해서 사용 가능

```tsx
import { Suspense } from "react";
import { axiosInstance } from "./api/axios";
import Posts from "./components/Posts";

async function fetchPosts() {
  const { data } = await axiosInstance.get("/posts222");
  return data; // Promise 객체
}
export default function App() {
  return (
    <>
      <ErrorBoundary fallback={<p>Error!</p>}>
        <Suspense fallback={<p>Loading..</p>}>
          <Posts promise={fetchPosts()} />
        </Suspense>
      </ErrorBoundary>
    </>
  );
}
```

```tsx
import { Suspense } from "react";
import { axiosInstance } from "./api/axios";
import Posts from "./components/Posts";
import { ErrorBoundary } from "react-error-boundary";
import Error from "./components/Error";

async function fetchPosts() {
  const { data } = await axiosInstance.get("/posts");
  return data; // Promise 객체
}
export default function App() {
  return (
    <>
      <ErrorBoundary FallbackComponent={Error}>
        <Suspense fallback={<p>Loading..</p>}>
          <Posts promise={fetchPosts()} />
        </Suspense>
      </ErrorBoundary>
    </>
  );
}

//Error.tsx
export default function Error({
  error,
  resetErrorBoundary,
}: {
  error: Error;
  resetErrorBoundary: () => void;
}) {
  return (
    <>
      <div role="alert">
        <p>Something went wrong:</p>
        <pre style={{ color: "red" }}>{error.message}</pre>
        <button onClick={resetErrorBoundary}>Reset</button>
      </div>
    </>
  );
}
```

ux 고려한 로딩 코드

```tsx
import { useEffect, useState } from "react";

export default function Loading() {
  const [isShow, setIsShow] = useState(false);
  useEffect(() => {
    const timer = setIsTimeout(() => {
      setIsShow(true);
    }, 500);
    return () => clearTimeout(timer);
  }, []);
  return <>{isShow && <p>Loading..</p>}</>;
}

//App.tsx
<Suspense fallback={<Loading />}>
  <Posts promise={fetchPosts()} />
</Suspense>;
```
